## 자료 구분

- **연구 보고서**: 2026 차세대반도체 경진대회 제출 자료, 소프트웨어 구조·통합 시연·검증 결과 서술
- **프로그램 가이드**: 실제 사용 순서와 화면 예시, 총 23쪽
- **경진대회 포스터**: 전체 작업 흐름과 실험 시간 사례, 공동 개발 결과
- **프로그램 저장소**: 배포 코드와 구현 파일, 설계 문서, 테스트 기록

## 검증 범위

보고서에 기재된 GUI 통합 시연, 소프트웨어 자동 테스트, 별도의 실환경 검증은 독립된 증거로 구분합니다. 자동 테스트 통과 또는 Sentaurus 계산 종료는 생성 결과의 물리적 정확도를 자동으로 보증하지 않습니다.
